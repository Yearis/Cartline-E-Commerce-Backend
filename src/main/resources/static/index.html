Cartline is a robust, enterprise-grade backend for an e-commerce platform. It features a secure Dual-Token Authentication system, Role-Based Access Control (RBAC), and high-performance caching using Redis.

🚀 Key Features

🔐 Security & Authentication

  • Dual-Token System: Access Token (Short-lived JWT) & Refresh Token (Redis stored).
  • RBAC: Roles for USER, SELLER, and ADMIN.
  • OTP Verification: Secure email verification using Redis.

🛍️ Product & Catalog

  • Advanced Search: Filter by Brand, Category, Name, Seller.
  • Inventory Management: Full CRUD for Products and Categories.

🛒 Shopping Experience

  • Smart Cart: Redis-backed shopping cart for high speed.
  • Order Lifecycle: Place, track, and cancel orders.

🛠️ Tech Stack

  • Core: Java 21, Spring Boot 3.x
  • Data: MySQL 8.0, Hibernate JPA
  • Cache: Redis
  • Auth: Spring Security, JWT
  • DevOps: Docker, Docker Compose

⚙️ API Usage

This API follows RESTful conventions. You can use the button above to access the interactive Swagger documentation to test endpoints like:

  • POST /auth/register - Create a new account
  • GET /products - Browse the catalog
  • POST /cart/add - Add items to cart
